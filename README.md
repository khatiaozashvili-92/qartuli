## როგორ მუშაობს

- **🎴 ბარათები** — ერთ მხარეს კითხვა, დაჭერით გადმოტრიალდება და პასუხი ჩანს.
  „✓ ვიცი“ ბარათს სიიდან აშორებს, სანამ არჩეულ მასალას ბოლომდე არ გაივლი.
- **✍️ ტესტი** — თითო კითხვაზე 4 სავარაუდო პასუხი; პასუხები ყოველ ჯერზე ირევა,
  ბოლოს — ქულა და პროცენტი.
- **⚙️ ფილტრი** — აირჩევ, რომელი თავი ან თემა გინდა (თავებიც და ცალკეული თემებიც).
- ტელეფონზე ბარათი თითით გადაისრიალებს; პროგრესი ბრაუზერში ინახება.
- კლავიატურა: ბარათებზე ← → და Space; ტესტზე 1–4 და Enter.

## ტექნიკურად

სტატიკური საიტი — თითო წიგნი ერთი HTML ფაილია, ბიბლიოთეკების გარეშე.
მასალა (კითხვები და პასუხები) იმავე ფაილშია, `CARDS` და `QUIZ` მასივებად;
სამივე გვერდი ერთი შაბლონიდან აიწყო, ანუ ლოგიკა იდენტურია.
